## Project Overview

The BrightTV Viewership Data Analysis project explores customer viewing behaviour and usage patterns to understand how subscribers interact with the BrightTV platform.

The project involved data preparation, transformation, analysis, visualisation, and dashboard development. The analysis focused on identifying meaningful patterns in customer profiles, viewing behaviour, watch duration, channel usage, and viewing times.

The project demonstrates an end-to-end data analytics workflow, from raw data preparation in Databricks to interactive dashboards and presentation of business insights.

---

## Project Objectives

The main objectives of the analysis were to:

* Understand BrightTV subscriber viewing behaviour.
* Identify key viewership and usage trends.
* Analyse when customers are most active on the platform.
* Explore differences in viewing behaviour across customer groups.
* Identify popular channels and viewing periods.
* Transform raw viewership data into meaningful business insights.
* Present findings through dashboards and visualisations that support decision-making.

---

## Data Preparation and Analysis

Data cleaning, exploration, transformation, and analysis were performed in **Databricks using SQL**.

The project used two primary tables:

* User Profiles
* Viewership Data

Common Table Expressions (**CTEs**) were created for both tables to organise the transformation process and make the SQL analysis easier to manage.

The transformed tables were then joined to create a consolidated **Big Code Table**, which was used as the main analytical dataset.

### Data Transformation

Several additional variables were derived from the original data to support deeper analysis, including:

* Year
* Month
* Day of week
* Time buckets
* Watch hour
* Usage buckets
* Duration hours

These transformations made it possible to analyse viewing behaviour across different time periods and customer usage levels.
